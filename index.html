EPI Guard Backup

O EPI Guard Backup é uma ferramenta pessoal, de uso próprio, que copia todos os dias o backup do sistema EPI Guard (banco de dados, código-fonte e arquivos do modelo de detecção) para o Google Drive do próprio dono da ferramenta.

Não é um serviço público: não tem cadastro de usuários e não é oferecido a terceiros. O único usuário é o seu dono, que usa a própria conta do Google.

Para fazer a cópia, a ferramenta pede ao dono, uma única vez, permissão para criar e gerenciar no Google Drive somente os arquivos que ela mesma criar (escopo https://www.googleapis.com/auth/drive.file). Com essa permissão ela não consegue ver nem alterar nenhum outro arquivo do Drive.

EPI Guard Backup is a personal, single-user tool that copies daily backups of the owner's own EPI Guard system to the owner's own Google Drive. It is not a public service.
