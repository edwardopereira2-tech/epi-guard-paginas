Política de privacidade do EPI Guard Backup

Última atualização: 17 de novembro de 2026. Voltar à página inicial

Quem usa e para quê

O EPI Guard Backup é uma ferramenta pessoal de uso próprio. O único usuário é o seu dono, que a usa com a própria conta do Google para guardar, no próprio Google Drive, cópias de segurança do sistema EPI Guard que ele mesmo mantém. Ela não é oferecida a terceiros.

Quais dados do Google a ferramenta acessa

Somente o escopo https://www.googleapis.com/auth/drive.file: criar, ler, atualizar e apagar apenas os arquivos e as pastas que a própria ferramenta criou no Google Drive do dono. Ela não enxerga nenhum outro arquivo, e-mail, contato ou informação da conta.

O que é enviado ao Drive

Uma cópia diária do banco de dados do sistema EPI Guard, um pacote com o histórico do código-fonte e, quando mudam, os arquivos do modelo de detecção. Vídeos e clipes de câmera não são enviados. Esses arquivos ficam no Drive do dono; a ferramenta apaga automaticamente as cópias mais antigas de banco e de código (após 30 dias, sempre mantendo as mais recentes).

Compartilhamento, venda e uso de terceiros

Nenhum dado é coletado de outras pessoas, vendido, compartilhado, usado para publicidade, análise de comportamento ou treinamento de modelos, nem enviado a terceiros. Os dados vão apenas do servidor do dono para o Google Drive do dono.

Guarda das credenciais

A autorização concedida (token) fica num arquivo protegido no servidor do próprio dono. O dono pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.

Uso Limitado (Google API Services User Data Policy)

O uso e a transferência, para qualquer outro aplicativo, das informações recebidas das APIs do Google por este aplicativo seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

EPI Guard Backup's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
